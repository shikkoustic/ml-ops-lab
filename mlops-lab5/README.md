# Practical 05 — Config Files and Automated Tests

**Course:** SCSE3040 MLOps (ODD Semester 2026-27)

## What this practical does
Moves every hardcoded setting in the delivery-time code (test size, seed,
feature names, target) out of the Python and into `work/config.yaml`, reads it
back with `yaml.safe_load`, and trains purely from that config — then proves
the config is really in charge by changing `test_size` and getting a different
MAE with no code edits.

The second half writes automated tests with `pytest`: unit tests for
`orders.py` (`minutes_per_km`, `is_valid_order`), a deliberate break (`/` → `*`)
to confirm the tests actually catch something, behaviour tests for the model
(rain is never faster, farther is never faster, beats a mean baseline), and
shared fixtures in `conftest.py`. The whole suite runs with one command.

Tasks T1–T3 add a `training.max_rows` setting with `train_limited()`,
`work/test_speed.py`, and a traffic-level behaviour test.

## How to run
```
pip install pandas scikit-learn pyyaml pytest joblib
jupyter lab lab5.ipynb      # run all cells
cd work && python -m pytest -q
```
Everything in `work/` is regenerated by the notebook, so running it top to
bottom reproduces the whole folder.
